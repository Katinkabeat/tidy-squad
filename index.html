⚠️ Firebase not yet connected — data is local to this device only! To share this chore chart across all phones in real time, you need to connect it to a free Firebase database.

Quick setup (takes ~10 minutes, totally free):
  1. Go to console.firebase.google.com and sign in with Google.
  2. Click Add project, name it (e.g. family-chores), then click through and create it.
  3. In the left sidebar click Realtime Database → Create database. Choose Start in test mode and click Enable.
  4. Click the ⚙️ gear icon → Project settings. Scroll to Your apps, click </> Web, register the app, then copy the firebaseConfig object values.
  5. Open this HTML file in a text editor, find the section labelled FIREBASE CONFIGURATION near the top of the <script> block, and paste in your values.
  6. To share across phones: drag this HTML file to netlify.com/drop (free, no account needed). You'll get a URL — bookmark it on every phone!

Until then, all data is saved locally on this device only.
